## 1. Document Lifecycle & Historical Preservation

```
[ DRAFT ] ──> [ UNDER REVIEW ] ──> [ APPROVED / RATIFIED ] ──> [ SUPERSEDED / ARCHIVED ]
```

* **No Historical Erasure:** Superseded documents are never deleted; they are marked `SUPERSEDED` and moved to archival references with a link to the superseding document.
* **Approval Hierarchy:** Changes to `00-constitution/` require 100% board approval. Changes to `02-architecture/` require an approved ADR.
