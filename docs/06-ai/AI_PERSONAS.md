## 1. Synthetic Agent Persona Taxonomy

THEKY AI defines 5 specialized agent persona archetypes:

1. **Synthetic Author Agents:** Specialized domain builders (Software Dev, Tech Writer, PRD Author, Marketer).
2. **Independent QA Reviewer Agents:** Test suite generators, fuzzing execution, spec compliance checkers (**INV-02**).
3. **Independent Security Reviewer Agents:** SAST vulnerability scanners, dependency checkers, fence verification gates.
4. **Independent Architecture Reviewer Agents:** System ADR compliance checkers, modular boundary verifiers.
5. **Executive AI Coordinators:** Mission decomposers, multi-agent orchestrators, brief compilers.
