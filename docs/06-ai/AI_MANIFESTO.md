## 1. The Core AI Doctrine

THEKY AI is engineered on three unshakeable constitutional tenets:

1. **AI is an Execution Engine, Not a Conversational Chatbot:** We reject the paradigm of generic streaming chat boxes. AI operates as autonomous synthetic departments that state progress through audited Executive Briefs.
2. **Separation of Powers by Design (INV-02):** Author agents can NEVER approve or audit their own work. Independent Reviewer agents test, scan, and audit every output before human presentation.
3. **Local-First On-Device Intelligence (INV-04):** Compute runs on local user hardware by default. Cloud API model bursting is an optional, policy-guarded enhancement.

## 2. The Human-AI Relationship

Synthetic AI agents operate under delegated authority as **Synthetic Employees**. Human Principals retain absolute, unchallengeable authority over strategic direction, approvals, financial spend caps, and corporate governance.

```
[ Human Principal ] ── Declares Intent (`Cmd+K`)
       │
       ▼
[ Synthetic Executive Agent ] ── Orchestrates Department Execution
       │
       ▼
[ Synthetic Author Agents ]   ── Draft Code, Specs, & Models in Sandboxes
       │
       ▼
[ Independent Reviewers ]     ── Audit QA, Security, & Architecture
       │
       ▼
[ Executive Brief ]          ── Presented to Human Principal for 1-Click Approval
```
