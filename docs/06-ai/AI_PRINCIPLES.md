## The Ten Responsible AI Principles

1. **Principle 1 (Separation of Powers):** Author agents never audit or approve their own output (**INV-02**).
2. **Principle 2 (Human Finality):** Human Principals hold supreme veto and sign-off authority over all work.
3. **Principle 3 (Local-First Priority):** Compute runs on on-device NPUs/GPUs by default (**INV-04**).
4. **Principle 4 (Hardware Egress Gates):** Secret/Confidential data classifications hardware-block outbound cloud API calls (**INV-05**).
5. **Principle 5 (Honest Uncertainty):** Agents explicitly quantify uncertainty in briefs rather than hallucinating confidence.
6. **Principle 6 (Bounded Budgets):** Financial spending caps per department are enforced deterministically.
7. **Principle 7 (Immutable Traceability):** Every prompt token and model execution is logged in the hash-chain ledger (**INV-03**).
8. **Principle 8 (Vendor Agnosticism):** LLM calls are decoupled from proprietary model vendors (**INV-09**).
9. **Principle 9 (Zero Telemetry Mining):** User workspace memory is never harvested or used for external model training.
10. **Principle 10 (Single Accountable Brief):** Execution outputs consolidate into ONE decision brief (**INV-07**).
