## 1. Structural Layout Rules

1. **8px Grid Rhythm:** All structural layout containers, paddings, and panel widths adhere to an 8px base grid rhythm.
2. **Keyboard Focus Borders:** Wireframe blueprints explicitly define focus ring outlines for every interactive element.
3. **Bi-Directional Flipping (RTL / LTR):** Sidebar, drawer, and table column positions automatically mirror for Arabic (RTL) locales while maintaining identical structural hierarchy.
