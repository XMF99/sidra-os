## 1. Eleven Reusable Layout Templates

```
1. DASHBOARD LAYOUT  ── Executive flight deck grid with brief queue & DAG status.
2. WORKSPACE LAYOUT  ── Sovereign Markdown vault inspector & folder tree sidebar.
3. EDITOR LAYOUT     ── Plain text Markdown editor with context assistant drawer.
4. LIST LAYOUT       ── Dense data table with filter/grouping bar & bulk actions.
5. DETAIL LAYOUT     ── Main document canvas with right metadata inspector drawer.
6. ANALYTICS LAYOUT  ── Metric cards, token burn charts, & latency graphs.
7. SPLIT VIEW LAYOUT ── Side-by-side document comparison or code diff view.
8. INSPECTOR LAYOUT  ── Collapsible right drawer for node properties.
9. CANVAS LAYOUT     ── Primary unstructured working surface.
10. WIZARD LAYOUT    ── Step-by-step modal setup sequence.
11. SETTINGS LAYOUT  ── Tabbed preference categories & security controls.
```
