## 1. Accessibility Architecture Mandate

1. **WCAG AAA Compliance:** Color contrast ratios for text elements meet or exceed 7:1. Information is never conveyed by color alone.
2. **Keyboard Operability:** 100% of components support full keyboard control and visible focus rings (`sys.token.border.focus`).
3. **Screen Reader Semantics:** Component blueprints include ARIA live regions (`aria-live="polite"`) for real-time mission progress updates.
4. **Native Bi-Directionality:** Spacing, borders, and directional icons adapt dynamically to Arabic (RTL) and English (LTR) layouts.
