## 1. Semantic Color Role Taxonomy

Color in THEKY is structured strictly by semantic intent:

```
+---------------------------------------------------------------------------------------------------------+
|                                      ELEVEN SEMANTIC COLOR ROLES                                         |
+----------------------+----------------------+----------------------+------------------------------------+
| 1. SURFACE PRIMARY   | 2. BACKGROUND BASE   | 3. TEXT PRIMARY      | 4. BORDER NEUTRAL                  |
| • Canvas Working     | • Monastic Foundation| • High Contrast Body | • Subtle Division Line             |
+----------------------+----------------------+----------------------+------------------------------------+
| 5. SUCCESS STATUS    | 6. WARNING STATUS    | 7. DANGER / RISK     | 8. INFORMATION                     |
| • Audit Gate Passed  | • Spend Cap Approaching| • Fence Breach Block | • Context Hints & Citations        |
+----------------------+----------------------+----------------------+------------------------------------+
| 9. NEUTRAL ACCENT    | 10. LIGHT MODE ALIAS | 11. DARK MODE ALIAS  |                                    |
| • Hover Focus Ring   | • Inverted Surface   | • Default Monastic   |                                    |
+----------------------+----------------------+----------------------+------------------------------------+
```

---

## 2. Accessibility & Contrast Mandate

Every text-to-background color pair meets **WCAG AAA Accessibility Standards** ($\ge 7:1$ contrast ratio). Zero low-contrast grey text on dark grey surfaces.
