## 1. Six-Tier Component Taxonomy

THEKY categorizes all interface components into 6 structural tiers:

```
Tier 1: Atomic Primitives ──────> Buttons, Inputs, Badges, Chips, Text Elements
  └── Tier 2: Composites ──────────> Search Bars, Filter Grids, Form Groups
        └── Tier 3: Application ─────> Document Editors, Knowledge Tree Inspectors
              └── Tier 4: Enterprise ───> Multi-Sig Drawers, SIEM Log Tables, SCIM Sync
                    └── Tier 5: AI ───────────> AI Employee Cards, Reviewer Gate Badges
                          └── Tier 6: Mission ──────> Mission DAG Nodes, Executive Brief Cards
```
