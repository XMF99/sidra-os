## 1. Six Project Screen Views

```
1. PROJECT LIST VIEW     ── High-level list of active sprint initiatives.
2. AGILE TASK BOARD VIEW ── Task columns (Backlog, Sandboxed, In Review, Done).
3. TASK DETAIL DRAWER    ── Sub-task breakdown, agent assignments, PRD links.
4. MILESTONE ROADMAP VIEW── Gantt chart of sprint deadlines & release horizons.
5. DEPENDENCY GRAPH VIEW ── Visualizer for task blocking dependencies.
6. PROJECT TIMELINE VIEW ── Velocity tracking & historical completion trends.
```
