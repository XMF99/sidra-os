## 1. Mobile Companion Scope & Boundaries

`THEKY Mobile` is engineered specifically as a **Lightweight Executive Brief Companion**.

```
+-----------------------------------------------------------------------------------+
|                        MOBILE SURFACE SCOPE BOUNDARIES                            |
|                                                                                   |
|  WHAT EXISTS ON MOBILE:                                                           |
|  ✅ Executive Brief Review & 1-Click Sign-Off (`Cmd+B` / FaceID).                 |
|  ✅ Priority Security / Budget Escalation Notifications (**INV-01**).              |
|  ✅ Voice Intent Capture for Command Center (`Cmd+K`).                            |
|                                                                                   |
|  WHAT DOES NOT EXIST ON MOBILE (DESKTOP ONLY):                                    |
|  ❌ Multi-file WASM code editing or local CLI debugging.                          |
|  ❌ Heavy local HNSW vector index building.                                       |
|  ❌ Enterprise SCIM / SAML platform administration.                               |
+-----------------------------------------------------------------------------------+
```
