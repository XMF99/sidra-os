## 1. Iconography Rules & Principles

Icons in THEKY function as **Pure Functional Markers**.

1. **Single Meaning Principle:** Every icon carries exactly ONE semantic meaning across all 25 modules.
2. **Enterprise Appropriateness:** Geometry is clean, precise, and non-decorative.
3. **RTL Mirroring:** Directional icons (e.g., navigation arrows, workflow step indicators) automatically mirror for Arabic (RTL) locales.
