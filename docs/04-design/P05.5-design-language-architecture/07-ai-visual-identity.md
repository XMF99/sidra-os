## 1. Professional AI Representation Charter

THEKY rejects cheesy AI tropes and childish visual representations. Synthetic AI agents are rendered as **High-Precision Engineering Subsystems**.

```
+-----------------------------------------------------------------------------------+
|                        AI VISUAL REPRESENTATION MATRIX                            |
|                                                                                   |
|  PERMITTED AI VISUAL STATES:                                                      |
|  • Execution State   ── Monospaced DAG Task Progress Meters.                      |
|  • Audit Pass State  ── Clean Independent Reviewer Audit Badge (**INV-02**).      |
|  • Certainty Score   ── Precise Numerical Confidence Metric (e.g., `0.98`).        |
|  • Human Sign-Off    ── Distinct Authoritative Principal Signature Icon (**INV-01**).|
|                                                                                   |
|  FORBIDDEN AI TROPES (STRICTLY PROHIBITED):                                       |
|  ❌ No magic wand icons, glowing sparkles, or rainbow gradients.                  |
|  ❌ No robot mascots, floating chat bubbles, or fake typing dots.                 |
+-----------------------------------------------------------------------------------+
```
