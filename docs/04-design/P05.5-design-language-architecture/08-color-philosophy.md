## 1. Semantic Color Usage Rules

Color in THEKY is reserved exclusively for **Semantic Status, Risk Signaling, and Priority Guidance**.

```
+---------------------------------------------------------------------------------------------------------+
|                                    SEMANTIC COLOR ROLE SPECTRUM                                         |
+----------------------+----------------------+----------------------+------------------------------------+
| 1. NEUTRAL CANVAS    | 2. PRIORITY / ACTION | 3. SUCCESS           | 4. RISK / EMERGENCY                |
| • 85%+ UI Surface    | • Brief Sign-Offs    | • Audit Gate Pass    | • Fence Violation & Security Block |
| • Monastic Dark/Light| • Primary Intent     | • Hash Ledger Commit | • Confidential Egress Warning      |
+----------------------+----------------------+----------------------+------------------------------------+
```

---

## 2. Color Application Constraints

* **Zero Decorative Color:** Color is never applied merely to make a page look colorful. 
* **Accessibility Ratio:** All text-to-background combinations must meet WCAG AAA contrast ratios ($\ge 7:1$).
