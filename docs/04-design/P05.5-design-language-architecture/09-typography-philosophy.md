## 1. Typography Hierarchy Spectrum

```
+-----------------------------------------------------------------------------------+
|                        TYPOGRAPHY APPLICATION SPECTRUM                            |
|                                                                                   |
|  1. Executive Scanning Hierarchy ── High-contrast headers for quick brief triage. |
|  2. Document Reading Hierarchy   ── Comfortable 60–75 character line lengths for  |
|                                     sovereign Markdown editing.                   |
|  3. Technical & Audit Hierarchy  ── Tabular monospaced alignment for code diffs,  |
|                                     hash ledgers, and token metering.             |
+-----------------------------------------------------------------------------------+
```

## 2. Bi-Directional Native Support (RTL / LTR)

Typography scale and spacing scale dynamically reflect reading orientation, maintaining identical visual hierarchy in Arabic (RTL) and English (LTR).
