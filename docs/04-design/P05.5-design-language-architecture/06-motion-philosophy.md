## 1. Functional Motion Philosophy

Motion in THEKY exists exclusively to provide **Spatial Orientation and State Confirmation**.

```
+-----------------------------------------------------------------------------------+
|                        MOTION HIERARCHY & DURATION RULES                          |
|                                                                                   |
|  • Instantaneous (<15ms) ── Command Palette Launch (`Cmd+K`) & Key Triggers.       |
|  • Rapid (100–150ms)     ── Panel Drawer Expansion & Split-View Toggles.          |
|  • Smooth (150–200ms)    ── Brief Queue Item Transitions & State Shifts.          |
|                                                                                   |
|  WHEN MOTION IS STRICTLY FORBIDDEN:                                              |
|  ❌ No bouncing AI chat avatars or animated glowing rings.                        |
|  ❌ No decorative page transition sweeps that delay content access.               |
|  ❌ No looping ambient background animations.                                     |
+-----------------------------------------------------------------------------------+
```
