## 1. Seven Immutable Visual Principles

```
1. CLARITY OVER DECORATION ── Every visual pixel must serve information understanding.
2. HIERARCHY BEFORE BEAUTY ── Information structure strictly dictates visual weight.
3. CONTENT OVER CHROME     ── The user's sovereign Markdown content is the primary Hero.
4. CALM INTERFACES         ── Neutral background tones, zero distracting badges (**INV-01**).
5. MINIMAL DISTRACTION     ── Subtle focus indicators; zero unsolicited popups.
6. HIGH INFORMATION DENSITY── Optimized data scanning for enterprise decision makers.
7. PROFESSIONAL ELEGANCE   ── Timeless design philosophy built to outlast visual trends.
```
