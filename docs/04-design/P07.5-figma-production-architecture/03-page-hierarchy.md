## 1. Standardized Page Ordering Spectrum

Every production Figma file must adhere to a standardized 6-level page structure:

```
1. ❖ Cover                ── Standard file thumbnail cover frame.
2. 📑 Overview & Changelog── Version history, file owner, & ADR integration links.
3. ❖ Production Canvas    ── Approved high-fidelity UI screens or component sets.
4. 🚀 Dev Handoff         ── Dev Mode annotated frames & token inspection specs.
5. 🧪 Interactive Demo    ── Flow connections & prototype behavior paths.
6. 🚧 Scratchpad / Archive── Exploration frames & superseded iteration archives.
```
