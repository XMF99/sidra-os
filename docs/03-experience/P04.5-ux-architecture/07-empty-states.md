## 1. Empty State Philosophy

Empty states in THEKY are **Actionable Launchpads**. They never display dead ends or blank white screens.

```
+-----------------------------------------------------------------------------------+
|                        SIX ACTIONABLE EMPTY STATE DESIGNS                         |
|                                                                                   |
|  1. New Workspace   ── Prompt to import existing Markdown folder or select template|
|  2. New Project     ── Prompt to state intent (`Cmd+K`) or create initial PRD.    |
|  3. No Memory       ── Guidance on local vector index creation and document sync.|
|  4. No AI Employees ── Direct links to hire synthetic staff from catalog.          |
|  5. No Documents    ── 1-click Markdown document creation prompt.                 |
|  6. No Missions     ── Clear prompt: "Type your first intent (Cmd+K)".          |
+-----------------------------------------------------------------------------------+
```
