## 2. Principle Specifications

1. **Mission First:** Users work on goal-oriented missions, never endless raw chat logs.
2. **Context First:** The system automatically assembles context from the local memory graph before asking for human input.
3. **One Mental Model:** The product behaves consistently across Desktop, Web, and Mobile.
4. **Progressive Disclosure:** Advanced settings and raw JSON logs remain hidden until explicitly requested.
5. **Human Authority Supremacy (INV-01):** Human sign-off is final; synthetic agents never approve their own work (**INV-02**).
