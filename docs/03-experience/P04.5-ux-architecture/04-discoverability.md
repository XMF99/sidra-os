## 1. Zero-Training Discoverability Engine

THEKY eliminates complex training manuals through 3 contextual discovery mechanisms:

1. **Command Palette Inline Discovery (`Cmd+K`):** Natural language queries automatically suggest executable commands, available agent skills, and relevant Markdown templates.
2. **Mission Contextual Hints:** When a user creates a new mission (e.g., *"Draft sales proposal"*), the system suggests relevant local memory graph links and connector integrations.
3. **Progressive Skill Exposure:** Advanced features (e.g., WASM capability fence tuning, multi-sig voting rules) are introduced only after the user successfully completes basic missions.
