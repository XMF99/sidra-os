## 1. Time-to-Value Target (<3 Minutes)

The first-time experience is engineered to achieve **First Value Delivery in under 180 seconds**:

```
[ Install App (<30s) ] ──> [ Auth & TPM Key Gen (<15s) ] ──> [ Declare Intent `Cmd+K` (<30s) ]
                                                                        │
                                                                        ▼
[ First Executed Brief Presented ] <── [ Synthetic Agent Task (<60s) ] ──┘
```

---

## 2. Non-Intrusive Guidance Rules

* **Zero Modal Popups:** THEKY never forces users to sit through multi-step onboarding carousels.
* **In-Context Execution:** The user learns by completing an actual live mission on minute 1.
