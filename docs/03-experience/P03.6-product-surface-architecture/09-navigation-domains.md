## 1. Eight Navigation Domains

Navigation in THEKY is divided into 8 functional cognitive domains:

```
1. GLOBAL DOMAIN        ── System launcher, universal search, user identity.
2. WORKSPACE DOMAIN     ── Vault switching, project hierarchies, document trees.
3. MISSION DOMAIN       ── Live mission execution DAGs, task logs, brief queue.
4. OBJECT DOMAIN        ── Direct link traversal between Documents, Customers, Deals.
5. AI DOMAIN            ── Agent rosters, memory graph visualization, skill packs.
6. ADMINISTRATION DOMAIN── SCIM provisioning, role permissions, billing settings.
7. DEVELOPER DOMAIN     ── Agent SDK docs, CLI test logs, sandbox configs.
8. MARKETPLACE DOMAIN   ── Agent catalog browsing, skill purchases, creator revenue.
```
