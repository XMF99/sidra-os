## 1. AI Employee Lifecycle Surface

Interacting with synthetic agents in THEKY is structured as a formal operational management process:

```
[ 1. Hiring / Provisioning ] ── Select Agent Pack from Marketplace or Local Catalog
              │
              ▼
[ 2. Charter & Fence Configuration ] ── Define path access, token budget, & supervisor
              │
              ▼
[ 3. Mission Assignment ] ── Dispatch intent via Command Center (`Cmd+K`)
              │
              ▼
[ 4. Sandboxed Execution ] ── Agent drafts code/specs; Independent Reviewer scans (**INV-02**)
              │
              ▼
[ 5. Executive Brief Sign-Off ] ── Human Principal reviews consolidated brief (`Cmd+Enter`)
              │
              ▼
[ 6. Decommission / Retirement ] ── Archive agent charter; revoke access keys
```

---

## 2. Escalation & Safety Protocols

If an AI Employee encounters an ambiguous constraint, budget ceiling alert, or security policy conflict, execution pauses immediately, and an **Escalation Ticket** is appended to the Principal's Executive Brief Queue (**INV-01**, **INV-05**).
