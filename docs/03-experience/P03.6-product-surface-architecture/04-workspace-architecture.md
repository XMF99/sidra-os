## 1. Workspace Surface Taxonomy

THEKY defines 7 workspace surface types:

1. **Personal Workspace:** Sovereign private notes, personal auth keys, private memory graph.
2. **Company Workspace:** Root organizational hierarchy, corporate ADRs, company memory.
3. **Mission Workspace:** Atomic intent execution sandbox for synthetic agent departments.
4. **Shared Workspace:** Encrypted multi-principal collaborative vault.
5. **Executive Workspace:** C-level decision queue, capital spend dials, ELA governance.
6. **Temporary Workspace:** Short-lived scratchpad for exploratory research.
7. **Sandbox Workspace:** Isolated container for testing unverified agent skills (**INV-05**).
