## 1. Collaboration Matrix

Collaboration in THEKY occurs along two distinct axes: **Human-to-AI Delegation** and **Agent-to-Agent Verification**.

```
[ Human Principal ] ── Declares Intent (`Cmd+K`)
       │
       ▼
[ Executive AI Coordinator ] ── Dispatches Tasks to Synthetic Departments
       │
       ▼
┌─────────────────────────────────────────────────────────────┐
│                Agent-to-Agent Execution Mesh                │
│                                                             │
│  Synthetic Author Agent ──> Isolated Sandbox Draft          │
│                                      │                      │
│                                      ▼                      │
│  Independent Reviewer Agent ──> QA & Security Audit Gate     │
└──────────────────────────────┬──────────────────────────────┘
                               │ (100% Pass Rate)
                               ▼
[ One Consolidated Brief ] ──> [ Human Principal Sign-Off ]
```

---

## 2. Fundamental Collaboration Rules

1. **Human Finality:** Human Principals have sole sign-off authority (**INV-01**).
2. **Reviewer Independence:** Author agents cannot audit or approve their own output (**INV-02**).
3. **Honest Uncertainty:** Agents must explicitly quantify uncertainty scores (0.0 to 1.0) rather than hallucinating confidence.
