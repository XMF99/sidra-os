## 1. Cognitive Navigation Paradigm

THEKY rejects menu trees, complex nested sidebars, and multi-level hamburger dropdowns. Navigation in THEKY is structured around **Direct Intent & Relationship Traversal**.

```
+-----------------------------------------------------------------------------------+
|                        COGNITIVE NAVIGATION MODES                                 |
|                                                                                   |
|  1. Intent Navigation (`Cmd+K`) ── Direct activation of any action/doc in <15ms.  |
|  2. Brief Navigation (`Cmd+B`)  ── Direct focus on the active Executive Brief.    |
|  3. Graph Navigation (`Cmd+M`)  ── Traversal along organizational memory links.   |
|  4. Vault Navigation (`Cmd+V`)  ── Direct inspection of local sovereign Markdown.  |
+-----------------------------------------------------------------------------------+
```

---

## 2. Navigation Performance & Flow Rules

* **Sub-50ms Navigation Rule (INV-06):** Transitioning between the Executive Brief View, Vault Inspector, or Command Launcher must complete in under 50ms to preserve cognitive flow state.
* **Context Preservation:** Navigating to inspect a source document from a brief preserves the user's scroll position and active decision state automatically.
