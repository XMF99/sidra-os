## 1. How THEKY Thinks (The Cognitive Operating Model)

THEKY does not process requests as an isolated chat prompt engine. THEKY thinks as a **Sovereign Organizational Cognition Engine**.

```
[ Human Intent Statement (`Cmd+K`) ]
                │
                ▼
[ Phase 1: Intent Perception & Context Injection ]
  • Parse intent action & target objects
  • Retrieve local memory graph context & active ADR constraints
                │
                ▼
[ Phase 2: Mission Graph & Task Decomposition ]
  • Decompose intent into Directed Acyclic Graph (DAG) of departmental missions
  • Assign tasks to Synthetic Author Agents (Eng, Product, Finance, Marketing)
                │
                ▼
[ Phase 3: Bounded Execution & Independent Verification ]
  • Execute task drafts in sandboxed workspace vaults
  • Trigger Independent QA and Security Reviewer Gates (**INV-02**)
                │
                ▼
[ Phase 4: Brief Synthesis & Executive Presentation ]
  • Consolidate outputs into ONE decision-ready Executive Brief (**INV-07**)
  • Quantify uncertainty and present 1-click decision prompts
```

---

## 2. Compounding Organizational Intelligence

Every completed mission, verified decision, and hash ledger entry feeds back into the local organizational memory graph:

* **Context Compounds:** The system becomes exponentially faster and more accurate at parsing human intent because it possesses the historical graph of past ADRs, code style rules, and budget limits.
* **Deterministic Reasoning:** Non-deterministic generative AI is strictly bounded within task drafting; model routing, capability evaluation, and ledger logging run 100% deterministically.
