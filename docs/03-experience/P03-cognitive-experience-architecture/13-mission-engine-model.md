## 1. The 9-Stage Mission Lifecycle

The Mission Engine is the central cognitive heart of THEKY OS. It governs the end-to-end transformation of human intent into verified corporate execution.

```
[ Stage 1: Intent Declaration (`Cmd+K`) ]
                    │
                    ▼
[ Stage 2: Planning & Context Injection ]
                    │
                    ▼
[ Stage 3: Mission Graph Decomposition (DAG Task Creation) ]
                    │
                    ▼
[ Stage 4: Department & Agent Assignment ]
                    │
                    ▼
[ Stage 5: Sandboxed Task Execution ]
                    │
                    ▼
[ Stage 6: Independent Reviewer Validation (QA + Security) ]
                    │
                    ▼
[ Stage 7: Executive Brief Review Compilation ]
                    │
                    ▼
[ Stage 8: Human Principal Sign-Off & Delivery ]
                    │
                    ▼
[ Stage 9: Organizational Memory Learning & Ledger Commit ]
```

---

## 2. Stage Breakdown & Cognitive Mechanics

* **Stage 1 (Intent):** Human Principal declares strategic intent via natural language command (`Cmd+K`).
* **Stage 2 (Planning):** System retrieves local graph context (`memory::graph`) and active ADR constraints.
* **Stage 3 (Decomposition):** System breaks intent into a Directed Acyclic Graph (DAG) of departmental missions.
* **Stage 4 (Assignment):** Tasks are assigned to specialized Synthetic Author Agents within capability fences.
* **Stage 5 (Execution):** Authors draft code, specs, or models in sandboxed workspace vaults.
* **Stage 6 (Validation):** Independent Reviewers run test suites, SAST scans, and spec compliance checks (**INV-02**).
* **Stage 7 (Review):** System consolidates outputs into **ONE Executive Brief** (**INV-07**).
* **Stage 8 (Delivery):** Principal reviews brief and issues 1-click sign-off (`Cmd+Enter`).
* **Stage 9 (Learning):** Hash block appends to ledger (**INV-03**), and memory graph updates with new knowledge.
