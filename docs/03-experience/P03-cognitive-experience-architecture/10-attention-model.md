## 1. Attention Protection Principles

Human attention is finite and fragile. In accordance with **INV-01 (Principal Attention Supremacy)**, THEKY enforces strict cognitive focus protection:

```
+-----------------------------------------------------------------------------------+
|                        ATTENTION PROTECTION RULES                                 |
|                                                                                   |
|  1. Zero Unsolicited Interruption ── No popups, toasts, or unread notification    |
|                                      badges during deep focus work.               |
|  2. Decision Queue Batching     ── Briefs are batched and presented at scheduled   |
|                                      executive review windows (e.g., 08:30 AM).   |
|  3. Max 3 Action Limit          ── Executive briefs render a maximum of 3 core   |
|                                      decision options per cycle.                  |
|  4. Emergency Override Only     ── Only critical security fence breaches or        |
|                                      financial spend leaks can interrupt focus.   |
+-----------------------------------------------------------------------------------+
```

---

## 2. Attention Modes

* **Focus Mode (Flow State):** All background agent progress notifications are suppressed. User works uninterrupted on primary task.
* **Executive Review Mode:** The system presents the consolidated **Executive Brief Queue** for 1-click strategic sign-offs (`Cmd+B`).
