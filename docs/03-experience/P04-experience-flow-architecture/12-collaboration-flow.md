## 1. Collaboration Interaction Matrix

```
1. HUMAN ↔ HUMAN: Multi-signature decision approvals (`governance::multisig`).
2. HUMAN ↔ AI: Natural intent delegation ➔ Consolidated Brief delivery.
3. AI ↔ AI: Synthetic Author Agent drafts ➔ Independent Reviewer audits (**INV-02**).
```

## 2. Conflict Resolution Rules

If two synthetic agents output conflicting recommendations, or if two co-founders submit conflicting voting tokens, the mission pauses and triggers a **Multi-Principal Deadlock Escalation** presented directly to the primary Principal.
