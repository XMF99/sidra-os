## 2. Standardized Journey Stages

Every user journey progresses through 7 operational milestones:
1. **First Day:** TPM key generation, workspace vault binding, default agent charter assignment.
2. **Daily Use:** Launch ➔ Executive Brief Queue (`Cmd+B`) ➔ 1-click sign-offs ➔ Intent declaration (`Cmd+K`).
3. **Weekly Use:** Milestone progress review, token spend auditing, memory graph consolidation.
4. **Mission Creation:** Natural language intent input ➔ DAG decomposition ➔ Department routing.
5. **Project Management:** Sprint milestone alignment, PRD links, active branch tracking.
6. **Delegation:** Synthetic agent assignment within WASM capability sandboxes (**INV-05**).
7. **Completion:** Independent Reviewer gate pass (**INV-02**) ➔ Hash ledger commit (**INV-03**).
