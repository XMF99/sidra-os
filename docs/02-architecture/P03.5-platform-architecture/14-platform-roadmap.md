## 1. Multi-Release Architecture Roadmap

```
[ Baseline: P00 - P03.5 ] ──> [ Release v1.0 GA ] ──> [ Release v2.0 Platform ] ──> [ Release v3.0 Sovereign ]
```

* **v1.0 GA Horizon:** Local Rust desktop shell, 7-vector model routing engine, Independent QA/Security Reviewer gates, SCIM 2.0 enterprise sync, core Google/Microsoft/GitHub connectors.
* **v2.0 Ecosystem Horizon:** Public 70/30 developer marketplace, `THEKY Mobile` brief companion, SAP S/4HANA & Oracle enterprise ERP connectors.
* **v3.0 Sovereign Horizon:** Air-gapped defense edition, custom local NPU neural acceleration models, zero-trust cross-organizational federated memory graphs.
