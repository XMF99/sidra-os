## 1. Version Format

THEKY releases follow **Semantic Versioning 2.0.0** (`MAJOR.MINOR.PATCH`):
* **MAJOR:** Incompatible API or governance changes (requires formal ADR).
* **MINOR:** Backward-compatible new capabilities or modules.
* **PATCH:** Backward-compatible bug fixes and security patches.
