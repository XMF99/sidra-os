## 1. Release Horizon Overview

```
[ v0.1 Alpha ] ──> [ v0.2 Closed Beta ] ──> [ v0.5 Public Beta ] ──> [ v1.0 GA ] ──> [ v2.0 Ecosystem ]
```

* **v0.1 (Internal Alpha):** Core Rust desktop kernel, local Markdown vault, `Cmd+K` launcher, local ledger writing.
* **v0.2 (Closed Beta):** 7-vector model router, Independent QA/Security Reviewer gates, spend cap manager.
* **v0.5 (Public Beta):** Free Sovereign Tier ($0/mo), Starter ($29/mo), Professional ($79/mo) PLG launch.
* **v1.0 (General Availability):** Business Plan ($199/mo), SCIM 2.0 provisioning, SAML SSO, SOC 2 Type II attestation.
* **v2.0 (Platform Ecosystem):** Third-party agent marketplace, `THEKY Mobile` FaceID companion.
