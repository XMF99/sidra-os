## 1. Technical Graphic Philosophy

THEKY rejects standard SaaS cartoon illustrations. All visual graphics function as **Technical Architectural Diagrams**:

```
+-----------------------------------------------------------------------------------+
|                        GRAPHIC PRODUCTION STYLE RULES                             |
|                                                                                   |
|  PERMITTED GRAPHIC STYLES:                                                        |
|  ✅ Clean monospaced vector node graphs and structural wireframe schematics.       |
|  ✅ Actionable Empty State Launchpads (e.g., "+ Create First Mission DAG Node").   |
|  ✅ High-precision data lineage visualizers.                                      |
|                                                                                   |
|  PROHIBITED GRAPHIC STYLES:                                                       |
|  ❌ No 3D cartoon characters, floating isometric human figures, or pastel shapes.|
|  ❌ No glowing magic wands, sparkles, or rainbow gradients.                       |
+-----------------------------------------------------------------------------------+
```
