## 1. Keyboard Traversal & Interaction Rules

1. **Sub-50ms Navigation SLAs (INV-06):** Triggering `Cmd+K` launches the Command Palette overlay in <15ms. Switching workspace vaults re-binds encryption keys in <10ms.
2. **Keyboard Sign-Off Shortcut:** Pressing `Cmd+Enter` on an active Executive Brief card commits the human Principal sign-off and appends the SHA-256 block to the hash ledger stream (**INV-03**, **INV-07**).
3. **Arabic RTL Mirroring:** When set to Arabic locale, sidebars move to the right screen edge, breadcrumbs flow right-to-left, and directional icons flip horizontally.
