## 1. Collaboration Interaction Rules

1. **Sub-50ms Navigation SLAs (INV-06):** Task status drag-and-drop or column filtering executes layout updates in <15ms.
2. **Keyboard Sign-Off Shortcut:** Pressing `Cmd+Enter` on any pending brief or decision card commits the human Principal sign-off and appends the SHA-256 block to the hash ledger stream (**INV-03**, **INV-07**).
3. **Arabic RTL Mirroring:** When set to Arabic locale, task Kanban columns flow right-to-left, calendar hours display right-aligned, and directional navigation icons flip horizontally.
