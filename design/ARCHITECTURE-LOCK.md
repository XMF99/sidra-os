### Detailed Pillar Breakdown:
1. **Delegation Over Prompting:** The primary UI interaction is intent submission resulting in an **Executive Brief**, NOT a conversational text streaming window.
2. **Local-First Intelligence:** Core execution, vector memory indexing, and audit logging function 100% offline. Local hardware (Layer 1/2) executes baseline workloads; cloud APIs (Layer 4) are used purely for high-reasoning bursts.
3. **Human Authority Supremacy:** Synthetic agents possess zero independent legal, strategic, or financial authority. Only human Principals issue approvals.
4. **Bounded Autonomy & Hard Fences:** Agents cannot cross security boundaries, access unauthorized memory contexts, or exceed 24-hour token budget ceilings.

## 11. Design & Engineering Compliance Rules

Every future screen, workflow, data structure, API endpoint, and UI component must comply with the following non-negotiable design rules:

1. **Rule 1 (No Empty Prompt Windows):** Interfaces must never present an unguided, empty chat text box as a primary view.
2. **Rule 2 (No Unverified AI Output):** Raw, unreviewed generative text or code must never be inserted into production files without passing an independent Reviewer agent gate.
3. **Rule 3 (No Cloud-Only Features):** Every feature must have a functioning offline fallback mode on local hardware.
4. **Rule 4 (No Silent Data Egress):** No outbound network request containing user workspace context may be executed without verifying data classification policy.
5. **Rule 5 (No Destructive Un-audited Changes):** No state mutation may occur without emitting a cryptographically signed event to the local hash ledger.
